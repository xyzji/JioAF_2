# JODU51641 / JODU51642

These two models use the same overall access flow:

```text
USB-C
  -> Fastboot
  -> flash supplied recovery + recoveryfs
  -> reboot/reset
  -> run supplied ADB helper
  -> shell
  -> downgrade preparation
  -> ACS / heartbeat block
```

## Requirements

- Matching ODU model: **51641** or **51642**
- USB-C data cable
- ADB and Fastboot utilities on the host PC
- Matching model package:
  - `devices/51641/51641-adb.zip`
  - `devices/51642/51642-adb.zip`

Do not mix the 51641 and 51642 packages.

## 1. Enter Fastboot

Connect the ODU to the PC over USB-C.

```sh
fastboot devices
```

Press/hold the ODU reset button until Fastboot detects the device. Repeat `fastboot devices` while doing this.

Proceed only when a device serial is displayed.

## 2. Flash the supplied recovery images

Extract the matching ZIP package and use the recovery and recoveryfs images supplied inside it.

Typical flow:

```sh
fastboot devices
fastboot flash recovery <provided-recovery-image>
fastboot flash recoveryfs <provided-recoveryfs-image>
fastboot reboot
```

Use the actual filenames from the matching ZIP.

## 3. Reset and obtain the ADB shell

1. Allow the ODU to restart.
2. Reset the ODU as required by this recovery flow.
3. Run the ADB script included in the matching ZIP.
4. Confirm visibility:

```sh
adb devices
```

5. Open the shell:

```sh
adb shell
```

### Manual ADB fallback

The original project notes use empty `fake_sbin` stubs to temporarily shadow selected commands:

```sh
adb wait-for-device
adb push tools/fake_sbin /tmp/fake_sbin/

adb shell "chmod +x /tmp/fake_sbin/*; \
export PATH=/tmp/fake_sbin:$PATH; \
mount --bind /tmp/fake_sbin/pkill /usr/bin/pkill; \
mount --bind /tmp/fake_sbin/reboot /sbin/reboot; \
mount --bind /tmp/fake_sbin/recovery /usr/bin/recovery; \
which pkill; ps"

adb shell
```

## 4. Downgrade preparation

The persistent UBIFS volume differs by model:

| Model | Persistent volume |
|---|---|
| JODU51641 | `/dev/ubi2_0` |
| JODU51642 | `/dev/ubi1_0` |

### 51641

```sh
mkdir -p /tmp/ubi_edit
mount -t ubifs -o rw /dev/ubi2_0 /tmp/ubi_edit
cd /tmp/ubi_edit/usr/etc/versions
```

### 51642

```sh
mkdir -p /tmp/ubi_edit
mount -t ubifs -o rw /dev/ubi1_0 /tmp/ubi_edit
cd /tmp/ubi_edit/usr/etc/versions
```

Back up and inspect:

```sh
cp major_ver major_ver.bak
cat major_ver
```

For this documented downgrade flow, set `major_ver` to exactly:

```text
0
```

A direct shell method:

```sh
printf '0\n' > major_ver
cat major_ver
```

Expected output:

```text
0
```

Then:

```sh
sync
cd /
umount /tmp/ubi_edit
```

Do not reboot until unmount succeeds.

## 5. Disable ACS / heartbeat through /etc/hosts

Mount the correct persistent UBIFS filesystem.

### 51641

```sh
mkdir -p /tmp/ubi_edit
mount -t ubifs -o rw /dev/ubi2_0 /tmp/ubi_edit
cd /tmp/ubi_edit/etc
cp hosts hosts.bak
vi hosts
```

### 51642

```sh
mkdir -p /tmp/ubi_edit
mount -t ubifs -o rw /dev/ubi1_0 /tmp/ubi_edit
cd /tmp/ubi_edit/etc
cp hosts hosts.bak
vi hosts
```

Append the contents of:

```text
configs/acs-blocklist.hosts
```

Then:

```sh
sync
cd /
umount /tmp/ubi_edit
```

After reboot, verify the entries survived.
