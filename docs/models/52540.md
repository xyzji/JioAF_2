# JODU52540

JODU52540 follows the same WebUI firmware-update flow as JODU52041.

Firmware link retained from the original README:

```text
https://gofile.io/d/lJ0PaRWO
```

## Procedure

1. Confirm the ODU model is exactly **JODU52540**.
2. Download the intended 52540 firmware.
3. Open the ODU WebUI.
4. Open the firmware/update page.
5. Upload the 52540 firmware.
6. Start the update and do not interrupt power.
7. Allow the ODU to reboot completely.
8. Verify the installed version and connectivity.

## If the WebUI is disabled

If the WebUI is not available, use UART to obtain a shell first.

Project-documented shell password:

```text
oelinux123
```

Once you have the shell, recreate the active WebUI link:

```sh
rm -f /data/webui_active_link
ln -s /WEBSERVER/www/dist /data/webui_active_link
```

Validate the lighttpd configuration:

```sh
lighttpd -t -f /usr/sbin/lighttpd.conf
```

If validation succeeds, reload lighttpd:

```sh
kill -HUP $(pidof lighttpd)
```

Then open the WebUI and follow the normal firmware-update procedure above.

## ACS behavior

Project notes indicate that the intended 52540 image leaves ACS disabled persistently after the successful update, similar to the persistent end state desired on 51641/51642.

After reboot, verify the actual device state rather than assuming it succeeded:

```sh
ps | grep -E 'cwmp|tr069|heartbeat'
```

The project notes state that no additional reset should be required for the ACS-off state.
