# JODU52041

JODU52041 uses the WebUI firmware-update path.

## Repository file

```text
devices/52041/52041v18.img
```

## Procedure

1. Confirm the ODU model is exactly **JODU52041**.
2. Connect to the ODU locally.
3. Open the ODU WebUI.
4. Open the firmware/update page.
5. Select `devices/52041/52041v18.img`.
6. Start the update.
7. Do **not** remove power or disconnect the ODU while flash writing/reboot is in progress.
8. Allow the ODU to reboot fully.
9. Verify the firmware version and normal LAN/WAN operation.

Do not use the 51641/51642 Fastboot recovery instructions on 52041 unless you have independently validated that path for your hardware revision.
