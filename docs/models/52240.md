# JODU52240

JODU52240 follows the same general WebUI update flow as JODU52041.

Firmware link retained from the original README:

```text
https://gofile.io/d/O8tz9cfA
```

## Procedure

1. Confirm the ODU model is exactly **JODU52240**.
2. Download the intended 52240 firmware.
3. Open the ODU WebUI.
4. Open the firmware/update page.
5. Upload the 52240 firmware.
6. Start the update and do not interrupt power.
7. Allow the ODU to reboot completely.
8. Verify the installed version and connectivity.

Add the firmware file to `devices/52240/` if you want it versioned with the repository, and publish its SHA-256 checksum.
