# JODU52140

JODU52140 uses UART for initial shell access.

## 1. UART shell

Connect to the ODU UART using the correct board pinout and electrical level.

Project-documented shell password:

```text
oelinux123
```

Back up persistent files before modifying them.

## 2. Post-boot configuration

Repository files:

```text
devices/52140/init.post_boot.sh
devices/52140/dropbearmulti
```

Back up the original:

```sh
cp /etc/init.post_boot.sh /etc/init.post_boot.sh.bak
```

Edit it to match the supplied repository file:

```sh
vi /etc/init.post_boot.sh
chmod +x /etc/init.post_boot.sh
sync
```

The supplied post-boot logic exposes an engineering-style `/lux_version`, starts BusyBox telnet on port 23, creates a Dropbear host key when required, and starts Dropbear SSH on port 22.

## 3. Dropbear SSH

Place `dropbearmulti` in `/persist/`, then:

```sh
cd /persist
chmod +x dropbearmulti

mkdir -p /etc/dropbear
/persist/dropbearmulti dropbearkey -t rsa -f /etc/dropbear/dropbear_rsa_host_key
/persist/dropbearmulti dropbear -p 22 -r /etc/dropbear/dropbear_rsa_host_key
```

Connect:

```sh
ssh root@192.168.225.1
```

Project-documented password:

```text
oelinux123
```

## 4. Disable ACS / CWMP / heartbeat

Persistent files identified by the project:

```text
/config/dc.conf
/etc/config/cwmp
/data/apps/jioapps/tr069/.configs/dm/config.save
/data/apps/jioapps/tr069/.configs/dm/cpestate.xml
/data/jio_heartbeat/jdhb.conf
```

### Back up all files

```sh
cp /config/dc.conf /config/dc.conf.bak
cp /etc/config/cwmp /etc/config/cwmp.bak
cp /data/apps/jioapps/tr069/.configs/dm/config.save /data/apps/jioapps/tr069/.configs/dm/config.save.bak
cp /data/apps/jioapps/tr069/.configs/dm/cpestate.xml /data/apps/jioapps/tr069/.configs/dm/cpestate.xml.bak
cp /data/jio_heartbeat/jdhb.conf /data/jio_heartbeat/jdhb.conf.bak
```

### Locate ACS links and credentials

```sh
grep -niE 'acs|cwmp|tr069|url|uri|server|user|username|pass|password' /config/dc.conf
grep -niE 'acs|cwmp|tr069|url|uri|server|user|username|pass|password' /etc/config/cwmp
grep -niE 'acs|cwmp|tr069|url|uri|server|user|username|pass|password' /data/apps/jioapps/tr069/.configs/dm/config.save
grep -niE 'acs|cwmp|tr069|url|uri|server|user|username|pass|password' /data/apps/jioapps/tr069/.configs/dm/cpestate.xml
grep -niE 'acs|cwmp|tr069|url|uri|server|user|username|pass|password' /data/jio_heartbeat/jdhb.conf
```

### Edit ACS values

Open:

```sh
vi /config/dc.conf
vi /etc/config/cwmp
vi /data/apps/jioapps/tr069/.configs/dm/config.save
vi /data/apps/jioapps/tr069/.configs/dm/cpestate.xml
vi /data/jio_heartbeat/jdhb.conf
```

For ACS/TR-069/CWMP configuration, change all applicable values while preserving each file's syntax:

- ACS server URL / remote ACS link
- ACS authentication username
- ACS authentication password
- explicit ACS/CWMP/TR-069 enable flags, where present
- Jio heartbeat URL/server values in `jdhb.conf`

Example disabled placeholders:

```text
ACS URL:  http://127.0.0.1/
Username: disabled
Password: disabled
```

For XML files, change only values and keep the XML structure valid.

### Hostname blocklist

Also use:

```text
configs/acs-blocklist.hosts
```

if the firmware exposes a persistent hosts file.

### Persist and verify

```sh
sync

ps | grep -E 'dropbear|telnetd|cwmp|tr069|heartbeat'
netstat -lnt 2>/dev/null | grep -E ':22|:23'
```

Reboot and verify the modifications survive.
